	LDAI => Load Accumulator with Immediate
	LDA  => Load Accumulator

	ADDI => Add immediate to accumulator
	STA  => Store Accumulator's value
	JMP  => Jump
	BGT  => Branch if Greater Than
	BLT  => Branch if Less Than
